# Narrate in a detected narration language that Cup checks against the speech model's own language list

Each audiobook is read in its narration language since [cup-audio/cup#220](https://github.com/cup-audio/cup/pull/220). Narration language detection asks a model for the language of the narration source material and falls back to the language the source page declares; [cup-audio/cup#224](https://github.com/cup-audio/cup/pull/224) added the narration language preferences for German and English, decided in [cup-audio/cup#223](https://github.com/cup-audio/cup/issues/223). Gemini accepts a well-formed tag for a language Flash-Lite TTS does not list, so Cup checks speakability itself ([conversion architecture](../architecture/conversion.md)). These decisions were recorded from code comments on 2026-11-23.

## Decision

- **Speakability is judged by the language subtag against Cup's own list.** [Narration language speakability](../../libs/audiobook-production/src/narration-language-speakability.ts) holds the languages Gemini 3.8 Flash-Lite TTS supports as canonical BCP 47 language subtags. Google lists them by name only (<https://ai.google.dev/gemini-api/docs/speech-generation#languages>, read on 2026-11-09). Several listed languages share one subtag (Chinese in Hans and Hant script, Kashmiri in Arab and Deva script, Standard Arabic in Arab and Latn script, and Iranian and Afghan Persian), and `Intl` canonicalizes some individual languages, such as Standard Latvian, to their macrolanguage. Each subtag stands for these names in Google's list: `ace` Acehnese (Arab script); `af` Afrikaans; `ak` Akan; `am` Amharic; `hy` Armenian; `as` Assamese; `awa` Awadhi; `ban` Balinese; `bn` Bangla; `bjn` Banjar (Latn script); `eu` Basque; `be` Belarusian; `bho` Bhojpuri; `bs` Bosnian; `bug` Buginese; `bg` Bulgarian; `yue` Cantonese; `ca` Catalan; `ceb` Cebuano; `ckb` Central Kurdish; `hne` Chhattisgarhi; `zh` Chinese (Hans and Hant script); `hr` Croatian; `cs` Czech; `da` Danish; `nl` Dutch; `arz` Egyptian Arabic; `en` English; `et` Estonian; `fil` Filipino; `fr` French; `gl` Galician; `lg` Ganda; `ka` Georgian; `de` German; `el` Greek; `gu` Gujarati; `ht` Haitian Creole; `mn` Halh Mongolian; `ha` Hausa; `he` Hebrew; `hi` Hindi; `hu` Hungarian; `is` Icelandic; `ilo` Iloko; `id` Indonesian; `fa` Iranian Persian and Persian (Afghanistan); `it` Italian; `ja` Japanese; `jv` Javanese; `kam` Kamba; `kn` Kannada; `ks` Kashmiri (Arab and Deva script); `kk` Kazakh; `km` Khmer; `ki` Kikuyu; `rw` Kinyarwanda; `kg` Kongo; `ko` Korean; `ky` Kyrgyz; `lo` Lao; `ln` Lingala; `mk` Macedonian; `mag` Magahi; `mai` Maithili; `ml` Malayalam; `mt` Maltese; `mni` Manipuri; `mr` Marathi; `min` Minangkabau (Arab script); `lus` Mizo; `ne` Nepali (individual language); `fuv` Nigerian Fulfulde; `az` North Azerbaijani; `nso` Northern Sotho; `uz` Northern Uzbek; `nb` Norwegian Bokmål; `nn` Norwegian Nynorsk; `ny` Nyanja; `or` Odia (individual language); `pl` Polish; `pt` Portuguese; `pa` Punjabi; `ro` Romanian; `ru` Russian; `sat` Santali; `sr` Serbian; `si` Sinhala; `sk` Slovak; `azb` South Azerbaijani; `pbt` Southern Pashto; `es` Spanish; `ar` Standard Arabic (Arab and Latn script); `lv` Standard Latvian; `ms` Standard Malay; `ta` Tamil; `te` Telugu; `tr` Turkish; `vi` Vietnamese.
- **Three outcomes.** A speech configuration's model speaks the narration language, cannot speak it, or ignores the narration language altogether, as ElevenLabs does.
- **A model change must register its languages.** A Gemini model without registered languages is a programmer error and throws, so a model change cannot silently turn every language unspeakable.
- **Segments record the manifest's narration language.** The [segment metadata](../../libs/audiobook-production/src/audio-segment-storage.ts) carries the manifest's narration language also when synthesis left it out of the request as unspeakable.
- **Narration language preferences.** [Narration language detection](../../libs/narration-source-analysis/src/narration-language-detection.ts) keys preferences by language subtag: the region a language is narrated with, and whether a region the narration language already has wins over it. A language gets a preference only when there is evidence that its regional variants sound wrong. All German is narrated as German from Germany, whatever region the page declares; English without a region is narrated as British English. A preferred narration language is only a language and a region, like the detector's answer with a declared region, so a fallback drops the script, variants and extensions of the declared tag.
- **Declared language.** `<html lang>` wins over `og:locale`, whose underscore form is converted to BCP 47 first.
- **What counts as a language.** BCP 47 also admits 5–8 letter language subtags, so a language name such as "German" parses as the tag `german`. Only a 2–3 letter ISO 639 subtag that `Intl` can name is a language, and the ISO 639 special codes name none.
- **The style carries the language.** The [Gemini request](../../libs/audiobook-production/src/synthesize-gemini-audio.ts) gives the text an unspoken style naming the language without its region ("German" for `de-AT`); that style is what makes a names-only segment, such as a byline, sound like the narration language, and the language parameter alone does not ([cup-audio/cup#193](https://github.com/cup-audio/cup/issues/193)).
- **Segment reuse compares the language.** The synthesis language is compared even when it is expected to be absent, so a segment synthesized in a narration language is not reused for a conversion without one ([audio segment storage](../../libs/audiobook-production/src/audio-segment-storage.ts)).
- **Evals.** The [narration content selection eval](../../libs/narration-source-analysis/test/evals/narration-content-selection.eval.ts) keeps its detection candidates separate from the selection candidates, so detection experiments vary independently of selection. The detection eval rebuilds the narration source material from the committed selection golden, leaving out the source title and source subtitle units, so a selection regression cannot fail detection. A fallback answers with the declared language, which can match without the detector deciding.

## Consequences

- Changing the Gemini speech model requires registering the new model's languages from Google's list.
- Google's list must be re-read by name and mapped to subtags by hand; the names above are the mapping's evidence.
- Adding a narration language preference needs evidence that a language's regional variants sound wrong.
